About MailCheck

A simple web application for bulk email checks.

Project Overview

MailCheck is a web application designed to check email address formatting and inspect domain DNS records to help identify potentially problematic email addresses.

Key Features

  • Bulk email verification
  • Email format validation
  • DNS and mail exchange (MX) record checks
  • Verification history stored in SQLite
  • Analytics dashboard for recorded results
  • CSV export of verification results

Technologies Used

  • Python: Backend logic
  • Flask: Web application framework
  • dnspython: DNS record lookups
  • SQLite: Local history database
  • HTML and CSS: User interface
  • JavaScript: Frontend interactions

Important Limitations

A successful DNS check does not prove that a particular mailbox exists. Results are estimates, not guarantees of email delivery.

MailCheck does not send emails or guarantee that an address can receive messages.
